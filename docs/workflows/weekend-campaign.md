# Campanha de final de semana

Entrada CampaignBrief → Director define orientação → SocialPlan → CopyPack → CreativeBrief → DirectorReview → Campaign DRAFT.

O Director aciona cada especialista com agents-as-tools. A próxima tool é habilitada depois da entrega validada da anterior.
As entregas são preservadas na composição final. Campanha incompleta ou Stories desalinhados falham sem salvar.
Implementação: src/realcenter_marketing/workflow.py.
