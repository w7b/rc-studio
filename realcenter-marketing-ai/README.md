# Dados locais do Real Center Studio

O código foi reorganizado em `../apps/backend` e `../apps/frontend`.

Esta pasta conserva `campaigns/`, `brand/`, `.env` e o ambiente Python local existente. Esses caminhos não foram migrados para preservar mídias, campanhas e IDs históricos.

Na raiz do projeto, execute:

```powershell
.\realcenter-marketing-ai\.venv\Scripts\python.exe scripts/run_backend.py
```

Consulte o README da raiz e `docs/architecture/blueprint.md`.
