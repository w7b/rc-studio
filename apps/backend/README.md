# Backend

Pacote `realcenter_marketing`, com domínio, aplicação, infraestrutura, apresentação e bootstrap. Os testes ficam em `tests/` e rodam da raiz com `python -m pytest`.

Instale da raiz com `python -m pip install -e './apps/backend[dev]'`. Execute `realcenter-studio` ou `python scripts/run_backend.py`. A CLI de campanhas permanece `realcenter-marketing`.

Os recursos versionados ficam em `resources/` na raiz; dados e Brand Kit ficam na raiz de dados configurada. Consulte `docs/architecture/blueprint.md` e o README principal para contratos e configuração.
